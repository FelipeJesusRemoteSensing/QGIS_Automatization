Automação PyQGIS + Gemini API

Criando seu Próprio Copiloto de IA no QGIS

Aprenda a construir um painel acoplável (QDockWidget) integrado ao QGIS, capaz de inspecionar as camadas abertas, enviar o contexto à API REST do Gemini e executar rotinas de geoprocessamento em tempo real.

1 Visão Geral da Arquitetura

Diferente de plugins pesados, esta solução opera como um script único executado diretamente no Console Python do QGIS. A comunicação ocorre em um pipeline contínuo de 5 etapas:

Prompt Texto do usuário
Contexto Varredura de camadas
API REST Chamada Gemini
Regex Extração do código
Execução Disparo via exec()

2 Anatomia do Script: Blocos Chave

Bloco A: Interface Gráfica com QDockWidget

O script herda de QDockWidget para criar um painel nativo que pode ser acoplado à direita ou esquerda do canvas do QGIS. Ele conta com um campo QPlainTextEdit para receber o comando do usuário e um QTextEdit de log formatado com HTML para inspecionar o código antes e depois da execução.

Bloco B: Injeção de Contexto Espacial (get_project_context)

Antes de enviar o prompt à LLM, o método itera por QgsProject.instance().mapLayers(). Ele lista o nome exato de cada camada carregada, sua geometria (Pontos, Linhas, Polígonos ou Raster) e seu SRC/CRS (ex.: EPSG:4674). Isso impede que a IA alucine nomes de camadas inexistentes.

Bloco C: System Instruction e Regras Críticas de PyQGIS

O prompt de sistema injeta regras que blindam a execução: instrui a LLM a diferenciar comandos diretos de processamento (processing.run) de pedidos de geração de modelos (QgsProcessingModelAlgorithm), além de proibir o uso de métodos obsoletos ou inexistentes como processingRegistry().addAlgorithm().

Bloco D: Regex e Execução Dinâmica (process_command)

A resposta da API é filtrada por uma expressão regular que isola blocos ```python ... ```. O código limpo é então injetado na função nativa exec() com acesso ao escopo de variáveis ativas (iface e QgsProject).

3 Como Instalar e Rodar no QGIS

1

Obtenha sua Chave da API Gemini

Acesse o Google AI Studio, gere uma chave de API gratuita e substitua na variável GEMINI_API_KEY do script (ou use variável de ambiente para produção).

2

Abra o Console Python do QGIS

No QGIS, pressione Ctrl + Alt + P ou navegue em Complementos > Console Python.

3

Cole e Execute o Script

Clique no ícone de bloco de notas para abrir o editor interno, cole o script Python completo e aperte no botão verde de Play. O dock aparecerá instantaneamente acoplado à sua barra lateral direita.

5 Resolução de Erros e Boas Práticas

HTTP Error 404: Not Found Verifique se o nome do modelo no endpoint da API está correto (ex.: gemini-2.5-flash).
Erro de Projeção / CRS em Graus Ao pedir buffers métricos, garanta que a camada esteja em CRS projetado (UTM/SIRGAS2000).
Cuidado com a Segurança do exec() Sempre revise o código impresso na caixa de log antes de executá-lo em dados de produção.

import json
import os
import re
import urllib.request
from qgis.core import QgsProject
from qgis.PyQt.QtCore import Qt
from qgis.PyQt.QtWidgets import (
    QDockWidget,
    QHBoxLayout,
    QLabel,
    QPlainTextEdit,
    QPushButton,
    QTextEdit,
    QVBoxLayout,
    QWidget,
)
from qgis.utils import iface

# Configure sua chave de API do Google AI Studio
GEMINI_API_KEY = os.getenv("GEMINI_API_KEY", "SUA_CHAVE_AQUI")
MODEL_NAME = "gemini-2.5-flash"

class GeminiQGISDock(QDockWidget):

    def __init__(self, parent=None):
        super().__init__("Gemini QGIS Copilot", parent)
        self.setAllowedAreas(
            Qt.DockWidgetArea.LeftDockWidgetArea | Qt.DockWidgetArea.RightDockWidgetArea
        )

        widget = QWidget()
        layout = QVBoxLayout(widget)

        layout.addWidget(QLabel("Comando em Linguagem Natural:"))
        self.input_prompt = QPlainTextEdit()
        self.input_prompt.setPlaceholderText(
            "Ex: Mude a cor da camada ativa para verde claro e aplique transparência de 50%"
        )
        self.input_prompt.setFixedHeight(80)
        layout.addWidget(self.input_prompt)

        btn_layout = QHBoxLayout()
        self.btn_run = QPushButton("⚡ Executar Ação")
        self.btn_run.clicked.connect(self.process_command)
        btn_layout.addWidget(self.btn_run)
        layout.addLayout(btn_layout)

        layout.addWidget(QLabel("Log / Código Executado:"))
        self.log_area = QTextEdit()
        self.log_area.setReadOnly(True)
        layout.addWidget(self.log_area)

        self.setWidget(widget)

    def get_project_context(self):
        """Extrai informações detalhadas das camadas abertas no projeto."""
        layers = QgsProject.instance().mapLayers().values()
        info = []
        for l in layers:
            tipo = "Raster"
            if hasattr(l, "geometryType"):
                geom_names = {0: "Pontos", 1: "Linhas", 2: "Polígonos", 3: "Desconhecido/Nulo"}
                tipo = f"Vetor ({geom_names.get(l.geometryType(), 'Outro')})"
            info.append(f"- Camada: '{l.name()}', Tipo: {tipo}, CRS: {l.crs().authid()}")
        return "\n".join(info) if info else "Nenhuma camada carregada no projeto."

    def call_gemini_api(self, prompt, context):
        url = f"https://generativelanguage.googleapis.com/v1beta/models/{MODEL_NAME}:generateContent?key={GEMINI_API_KEY}"

        system_instruction = f"""Você é um especialista em automação e desenvolvimento no QGIS (PyQGIS 3).

Contexto atual das camadas no projeto:
{context}

DIRETRIZES DE EXECUÇÃO:
1. SE O USUÁRIO PEDIR UM "MODELO" (.model3 / Designer de Modelos):
   - Crie uma subclasse de `QgsProcessingModelAlgorithm` salvando o arquivo na pasta oficial de modelos do QGIS (`QgsApplication.qgisSettingsDirPath() + 'processing/models/'`).
2. SE O USUÁRIO PEDIR UMA "AUTOMAÇÃO / EXECUÇÃO DIRETA":
   - Use `processing.run()` ou `processing.runAndLoadResults()`.
   - Encadeie as saídas usando `output['OUTPUT']` como entrada do próximo passo.

REGRAS CRÍTICAS:
- Retorne APENAS código Python puro executável, dentro de blocos ```python ... ```.
- Atualize sempre o canvas após modificações visuais usando `iface.mapCanvas().refresh()`.
- NUNCA use `QgsApplication.processingRegistry().addAlgorithm()`, pois o método NÃO existe.
"""

        payload = {
            "systemInstruction": {"parts": [{"text": system_instruction}]},
            "contents": [{"parts": [{"text": prompt}]}],
            "generationConfig": {"temperature": 0.1},
        }

        req = urllib.request.Request(
            url,
            data=json.dumps(payload).encode("utf-8"),
            headers={"Content-Type": "application/json"},
        )

        with urllib.request.urlopen(req, timeout=30) as response:
            res_json = json.loads(response.read().decode("utf-8"))
            return res_json["candidates"][0]["content"]["parts"][0]["text"]

    def process_command(self):
        prompt_text = self.input_prompt.toPlainText().strip()
        if not prompt_text:
            return

        self.btn_run.setEnabled(False)
        self.log_area.append(f"\nPrompt: {prompt_text}")

        try:
            context = self.get_project_context()
            raw_response = self.call_gemini_api(prompt_text, context)

            # Extrai o código Python da resposta via Regex
            code_match = re.search(r"```(?:python)?\s*(.*?)\s*```", raw_response, re.DOTALL)
            code = code_match.group(1) if code_match else raw_response.strip()

            self.log_area.append(
                f"
{code}
"
            )

            # Executa com acesso às instâncias ativas do QGIS
            local_scope = {"iface": iface, "QgsProject": QgsProject}
            exec(code, globals(), local_scope)

            self.log_area.append("✓ Executado com sucesso!")
            self.input_prompt.clear()

        except Exception as e:
            self.log_area.append(f"Erro: {str(e)}")

        finally:
            self.btn_run.setEnabled(True)

# Limpeza para evitar janelas duplicadas ao reexecutar
try:
    gemini_dock.close()
    iface.removeDockWidget(gemini_dock)
except:
    pass

gemini_dock = GeminiQGISDock(iface.mainWindow())
iface.addDockWidget(Qt.DockWidgetArea.RightDockWidgetArea, gemini_dock)
